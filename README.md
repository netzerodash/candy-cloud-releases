# Candy Cloud สำหรับ Android

ดาวน์โหลด APK รุ่นทดสอบล่าสุด **1.0.0 (7)** จาก [GitHub Releases](https://github.com/netzerodash/candy-cloud-releases/releases/latest)

- `CandyCloud-1.0.0-7.apk` — รุ่นทดลอง Android ที่เปิดใช้การวาดเงาแบบ cached raster และมีการแก้ไขการเล่น Replay, ปุ่มควบคุม และการแสดงผล Racing

รุ่นนี้เป็น candidate สำหรับทดสอบ ยังไม่ใช่ผลยืนยันประสิทธิภาพหรือการแก้ปัญหาภาพกะพริบบนอุปกรณ์ Android ทุกรุ่น ลงทะเบียน Android OAuth client และตั้งค่าฝั่งเซิร์ฟเวอร์แล้ว แต่ยังต้องทดสอบ Google Sign-In บนอุปกรณ์จริงก่อนยืนยันการใช้งาน ระหว่างนี้สามารถใช้ Guest ได้ ฟีเจอร์ออนไลน์ต้องเชื่อมต่ออินเทอร์เน็ต

## วิธีติดตั้ง

1. ดาวน์โหลด APK จากหน้า Releases ลงในอุปกรณ์ Android
2. เปิดไฟล์ APK หาก Android ขออนุญาต ให้เปิดสิทธิ์ติดตั้งแอปจากแหล่งนี้สำหรับแอปที่ใช้ดาวน์โหลดหรือตัวจัดการไฟล์
3. กดยืนยันติดตั้ง แล้วเปิด Candy Cloud

APK รุ่นใหม่ใช้ package, signing key และ version code เดิม จึงติดตั้งทับเพื่ออัปเดตแอปเดิมและเก็บข้อมูลแอปไว้ได้

ตรวจสอบไฟล์ก่อนติดตั้งได้ด้วย `sha256sum -c SHA256SUMS` โดยวาง APK และ `SHA256SUMS` ไว้ในโฟลเดอร์เดียวกัน
